ALBUM LINER NOTES

라네즈의 브랜드 무드를 유지한 웹 UI 재설계

라네즈 공식몰의 맑고 깨끗한 브랜드 이미지는 유지하면서, 복잡하게 느껴질 수 있는 메뉴와 콘텐츠 구조를 정리해 웹사이트를 재설계했습니다. 메인 페이지와 워터뱅크 카테고리 페이지를 중심으로 정보 위계를 단순화하고, 제품 탐색이 자연스럽게 이어지도록 레이아웃과 인터랙션을 구성했습니다.

MY CONTRIBUTION

맑은 브랜드 인상을,
끊김 없는 탐색 경험으로.

  1. 01
    브랜드 비주얼 재구성

    라네즈의 수분감과 깨끗한 이미지를 블루 포인트, 넓은 여백, 선명한 제품 비주얼로 정리해 웹 환경에 맞는 브랜드 무드로 재구성했습니다.

  2. 02
    제품 탐색 구조 개선

    메인에서 제품 카테고리와 상세 정보로 자연스럽게 이어질 수 있도록 콘텐츠 순서와 정보 위계를 정리하고, 주요 행동을 쉽게 찾을 수 있도록 배치했습니다.

  3. 03
    반응형 인터랙션 구현

    HTML, CSS, JavaScript를 활용해 화면을 구현하고, 다양한 화면 크기에서도 콘텐츠 흐름과 탐색 순서가 유지되도록 레이아웃과 인터랙션을 조정했습니다.
