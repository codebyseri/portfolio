MY CONTRIBUTION

쇼핑의 흐름을 분석하고,
재사용 가능한 구조로 구현.

  1. 01
    서비스 화면과 동선 분석

    FILA 공식몰의 메인, 상품 목록, 상세, 장바구니로 이어지는 구매 흐름을 살펴보고 구현에 필요한 화면과 공통 UI 요소를 정리했습니다.

  2. 02
    컴포넌트 구조 설계

    반복되는 상품 카드와 인터페이스를 React 컴포넌트로 분리해 화면마다 일관된 표현을 유지하고 이후 수정이 쉬운 구조로 만들었습니다.

  3. 03
    상호작용과 상태 구현

    호버, 아코디언, 레이어 팝업과 장바구니 흐름을 연결해 단순한 화면 재현을 넘어 실제 쇼핑 과정처럼 사용할 수 있도록 구현했습니다.
